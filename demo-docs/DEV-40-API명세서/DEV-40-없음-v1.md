## ＊ 개요
공개 HTTP API를 두지 않는다(DEV-10, DEV-20). 아래 표의 없음은 빈칸이 아니라, 그 칸을 v1에 두지 않는다는 결정이다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| 없음 | 없음 | 이 한 행이 v1 엔드포인트 계약의 전부다. 공개 경로를 추가하지 않는다 |

| 코드 | 의미 |

| 없음 | HTTP 상태 코드는 만들지 않는다. 로컬 저장이 실패하면 반환값을 여기서 정하지 않고 DEV-30 미결 2가 닫힌 뒤 그 문장의 값을 이 칸에 옮긴다 |
