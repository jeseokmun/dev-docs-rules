## ＊ 제목
로컬 DB로 drift(또는 동등 typed SQL)를 채택한다.

## ＊ 맥락
체크인·습관은 기기에만 저장한다. UI가 DB에 직접 가지 않는 구조를 DEV-30이 전제하므로, 마이그레이션·타입 안전이 있는 로컬 SQL 레이어가 필요하다. 구현체는 아직 코드에 없음.

## ＊ 결정
`infrastructure`에서 **drift**를 기본 후보로 둔다. 최종 accepted는 스파이크 후.

## ＊ 이유
| # | 이유 |
|---|---|
| 1 | 스키마·쿼리 타입이 컴파일 타임에 잡혀 streak/날짜 버그를 줄이기 쉽다 |
| 2 | 마이그레이션 경로가 명확해 위험 구역을 문서화하기 좋다 |

## ＊ 버린 대안
| 대안 | 버린 이유 |
|---|---|
| 순수 SharedPreferences | 관계형 체크인·주간 집계에 곧 한계 |
| sqflite 직접 | 동작하나 타입·마이그레이션 규율이 약함 |

## ○ 결과·리스크
| 항목 | 내용 |

| 결과 | 학습·생성 코드량 증가 가능 |
| 리스크 | Flutter 버전과 drift 호환을 DEV-10 환경과 맞춰야 함 |
