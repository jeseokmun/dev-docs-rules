## 문서 성숙도
| 규칙 | 내용 |
|---|---|
| draft | ＊ 최소. 假채움 금지 → 미결 |
| 리뷰 | 보강 요청 목록 |
| active | 핵심 미결 폐쇄 + 검증 가능 |
| 이상형 | draft 실패 조건 아님 |

## 최소 기준
| 항목 | 최소 기준 |
|---|---|
| ＊ 엔드포인트 | 메서드+경로 ≥1 |
| ＊ 요청 | 헤더/바디 필드 또는 스키마 |
| ＊ 응답 | 성공 형태 |

| ＊ 인증 | 방식 또는 「없음」+사유 |
| 금지 | 실토큰·실키 |
