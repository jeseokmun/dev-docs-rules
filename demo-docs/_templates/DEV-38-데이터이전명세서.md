## 문서 성숙도
| 단계 | 내용 |
|---|---|
| 1 | 첫 작성 = **draft 최소(＊) 통과**. 이상 완성 아님. |
| 2 | 빈 ＊ → **미결**로 과제화. 假채움·`_…_` 단독 금지. |
| 3 | 리뷰는 **보강 요청 목록**. 이상형 미달 ≠ draft 실패. |
| 4 | **active** = 핵심 미결 폐쇄 + 검증 가능 후. |
| 5 | 코드·사실이 문서를 이기면 갱신하거나 deprecated. |

## 최소 기준 (미달이면 draft 유지)
| 항목 | 최소 기준 |
|---|---|
| ＊ 대상 | 무엇→무엇·버전 |
| ＊ 절차 | ≥3단계 — 변환·검증 열 |
| ＊ 롤백 | 실패 시 — **표** |
| ＊ 검증 | 성공 확인 ≥1 |
