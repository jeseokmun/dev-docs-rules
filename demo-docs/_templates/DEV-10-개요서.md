## 표기
- **＊** 필수 · **○** 권장 · **□** 선택

## 문서 성숙도
1. draft = ＊ 최소 통과. 假채움 금지 → 미결.
2. 리뷰는 보강 요청 목록.
3. active = 핵심 미결 폐쇄 + 검증 가능.
4. 스크린샷 비강제.

## 최소 기준
| 항목 | 최소 기준 |
|---|---|
| ＊ 한 줄 소개 | 동사·범주, 20–80자 |
| ○ 동기 | 문제 1 + 접근 1 (표 또는 2문장) |
| ＊ 누구 | 사용자≥1 + 비사용자≥1 (표) |
| ＊ 핵심 기능 | 3–5행 표, 동사 |
| ＊ 실행 | 개발/사용자/환경 표 3행 |
| ＊ 경계 | ≥2행 표 |
| ○ 성공·검증 | 표로 짝 |
