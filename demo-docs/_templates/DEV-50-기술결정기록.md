# 템플릿 — DEV-50 기술결정기록 (v2.1)

> **v1 기준본 양식**. 개정 시 템플릿·헌법 §0을 함께.  
> **가독성:** 표 우선. 산문은 요약만.  
> **경로:** `{docs_root}/DEV-50-기술결정기록/DEV-50-{슬러그}.md` (다건)

## 표기
| 기호 | 의미 |
|---|---|
| ＊ | 필수 |
| ○ | 권장 |
| □ | 선택 |

## 문서 성숙도
| 규칙 | 내용 |
|---|---|
| draft | ＊ 최소. 假채움 금지 → 미결 |
| 리뷰 | 보강 요청 목록 |
| active | 핵심 미결 폐쇄 + 검증 가능 |
| 이상형 | draft 실패 조건 아님 |

## 최소 기준
| 항목 | 최소 기준 |
|---|---|
| ＊ 제목 | 결정이 한눈에 |
| ＊ 문서 상태 | draft/active/deprecated |
| ＊ 결정 상태 | proposed/accepted/superseded — 문서 상태와 별개 |
| ＊ 맥락 | 2–5문장 또는 표 |
| ＊ 결정 | 무엇을 골랐는지 |
| ＊ 이유 | ≥2행 |
| ＊ 버린 대안 | ≥1+이유 |
| 인덱스 | 결정 없으면 「결정 없음」+사유 |
