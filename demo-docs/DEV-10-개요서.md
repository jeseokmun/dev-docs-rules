## ＊ 한 줄 소개
휴대폰에만 저장되는, 혼자 쓰는 습관 체크·연속 기록 앱이다.

## ○ 왜 필요한가
| 구분 | 내용 |
|---|---|
| 문제 | 습관 앱이 가입·소셜·광고를 요구하는 경우가 많음 |
| 접근 | 가입 없이 오늘 했는지/연속 일수만 빠르게 본다 |

## ＊ 누구를 위한가
| 구분 | 내용 |
|---|---|
| 사용자 | 혼자 운동·독서를 기록하려는 개인 |
| 비사용자 | 팀 챌린지·클라우드 동기화가 필요한 사람 |

## ＊ 핵심 기능
| # | 사용자가 하는 일 |
|---|---|
| 1 | 습관 이름·주당 목표를 추가·수정·삭제 |
| 2 | 오늘 날짜에 체크/해제 |
| 3 | 습관별 streak 숫자 확인 |
| 4 | 이번 주 체크 횟수 요약 보기 |

## ＊ 실행·설치
| 구분 | 내용 |
|---|---|
| 개발 | `git clone <repo-url> && cd HabitCheck && flutter pub get && flutter run -d android` |
| 사용자 | 내부 APK `dist/habitcheck-v0.1.0.apk` 사이드로드 |
| 환경 | Android 8.0+ · Flutter 3.22+ · Dart 3.4+ |

## ＊ 시스템 경계
| 하지 않는 것 | 이유 |
|---|---|
| 계정·클라우드 동기화 | v1 범위 밖 |
| 친구·피드·푸시 | v1 범위 밖 |
| Health 연동 | v1 범위 밖 |

## ○ 성공·검증
| 성공 모습 | 검증 방법 |
|---|---|
| 7일 연속 체크 후 상세 streak=7 | 1) flutter run 2) 습관 추가 3) 날짜 바꿔 7회 체크 4) streak 7 확인 |
