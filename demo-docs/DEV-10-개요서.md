## ＊ 한 줄 소개
휴대폰에만 저장되는, 혼자 쓰는 습관 체크 앱이다. streak 계산은 HC-STREAK. 주인은 `DEV-30-구조명세서.md`다.

이 문서의 순서는 왜 필요한가, 사용자, 기능, 실행, 경계, 성공 확인, 관련 문서, 미결이다.

## ○ 왜 필요한가
| 구분 | 내용 |
|---|---|
| 문제 | 습관 앱이 가입·소셜·광고를 요구하는 경우가 많음 |
| 접근 | 가입 없이 오늘 했는지와 streak만 본다. 계산은 한 줄 소개의 HC-STREAK다 |

## ＊ 누구를 위한가
| 구분 | 내용 |
|---|---|
| 사용자 | 혼자 운동·독서를 기록하려는 개인 |
| 비사용자 | 팀 챌린지·클라우드 동기화가 필요한 사람 |

## ＊ 핵심 기능
| # | 사용자가 하는 일 |
|---|---|
| 1 | 습관 이름·주당 목표를 추가·수정·삭제 |
| 2 | 오늘 날짜에 체크/해제 |
| 3 | 습관별 streak 확인. 계산은 HC-STREAK. 주인은 `DEV-30-구조명세서.md`다 |
| 4 | 이번 주 체크 횟수 요약을 본다. 순위는 DEV-20의 Should이다. 플래그 기본값은 HC-FLAG. 주인은 `../_examples/DEV-52-기능플래그-주간요약.HabitCheck.md`다 |

## ＊ 실행·설치
| 구분 | 내용 |
|---|---|
| 개발 | `git clone <repo-url> && cd HabitCheck && flutter pub get && flutter run -d android`. `<repo-url>`은 저장소 주소가 아니다. HC-REPO는 값이 없다. 미결 1 |
| 사용자 | 사이드로드할 파일 이름은 `dist/habitcheck-v0.1.0.apk`다. HC-HASH는 값이 없다(DEV-90 미결 1). 만드는 절차는 예제 DEV-60 |
| 환경 | Android 8.0+ · Flutter 3.22+ · Dart 3.4+. 이 하한은 HC-PLATFORM이다. DEV-20은 이 하한으로 iOS를 뺀다. 기기별 측정표는 없다 |

## ＊ 시스템 경계
| 하지 않는 것 | 이유 |
|---|---|
| 계정·클라우드 동기화 | 가입 없이 기기에만 저장하는 것이 접근 방법이다. 공개 HTTP API는 없다(DEV-40) |
| 친구·피드 | 사용자는 혼자 쓰는 사람이고, 팀 챌린지가 필요한 사람은 비사용자다 |
| 리마인더 푸시 | 알림을 보낼 서버를 두지 않는다. 요구에서 뺀 기록은 DEV-20이고, 원격 전송을 하지 않는다는 기록은 DEV-55다 |
| Health 연동 | 입력은 사용자가 누른 체크뿐이다. 센서 연동은 DEV-20 비범위다 |

## ○ 성공·검증
| 성공 모습 | 검증 방법 |
|---|---|
| 상세 streak는 HC-STREAK. 주인은 `DEV-30-구조명세서.md`다 | 1) 미결 1의 주소로 개발 행을 실행한다. 2) 습관을 하나 추가한다. 3) DEV-70의 Clock으로 localDate를 옮겨 체크한다. 4) 기대 숫자는 그 주인 문장을 본다. 3)의 CLOCK_MODE 기본값은 DEV-45에서 미정이고, 그 재현 조건은 미결 3이다. |
