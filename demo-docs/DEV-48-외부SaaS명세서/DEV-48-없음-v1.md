## ＊ SaaS
| SaaS | 용도 | 데이터 | 중단시 |
|---|---|---|---|
| 없음 | 없음 | 없음 | 호출할 외부 서비스가 없으므로, 외부 장애와 무관하게 로컬 체크가 동작한다(DEV-10, DEV-20 오프라인) |

## ＊ 연동
읽는 순서는 SaaS 표, 연동, 한도, 미결이다. v1 호출 목록은 위 없음 한 행으로 끝난다.

| 항목 | 내용 |
|---|---|
| 방식 | 해당 없음. HTTP 클라이언트 연동도 없다(DEV-40) |
| 설정 키(이름만) | SaaS 키 행은 없다. 키 목록은 DEV-45 |

|---|---|---|
