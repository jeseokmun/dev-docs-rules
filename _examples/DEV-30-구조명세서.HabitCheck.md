## ＊ 한 줄 구조 요약
화면은 유스케이스만 호출한다. 유스케이스는 도메인과 로컬 저장을 부르고, 저장 계층은 행을 도메인 모델로 매핑해 되돌린다.

## ＊ 모듈/레이어
| 모듈 | 책임 | 비고 |
|---|---|---|
| 화면 presentation | 목록·상세·체크 UI | 유스케이스만 호출 |
| 유스케이스 application | 추가·오늘 체크·streak 조회 | 한 의도당 한 유스케이스 |
| 도메인 domain | Habit·CheckIn, streak, 날짜 경계 | streak 정의는 실행 흐름 절의 HC-STREAK 문장이다. 이 칸은 그 문장을 다시 쓰지 않는다 |
| 인프라 infrastructure | 로컬 DB, 마이그레이션, 시계 | 저장·조회와 모델 매핑 |

## ＊ 구조도 (Mermaid)

## ＊ 의존 규칙
| 방향 | 허용? | 설명 |
|---|---|---|
| 화면 → 유스케이스 | 허용 | 화면은 유스케이스만 호출 |
| 유스케이스 → 도메인 | 허용 | 날짜·streak 규칙은 도메인에 둔다 |
| 유스케이스 → 인프라 | 허용 | 저장과 조회. DEV-32 |
| 인프라 → 도메인 | 허용 | 저장된 행을 도메인 모델로 매핑 |
| 화면 → DB | 금지 | 화면이 DB를 직접 열지 않는다 |
| 도메인 → Flutter UI | 금지 | 도메인이 위젯·플러그인을 부르지 않는다 |

## ○ 핵심 실행 흐름

streak는 한 습관의 CheckIn.localDate만 센다. 가장 최근 체크인 날짜에서 하루씩 과거로 이어진 개수이고, 하루가 비면 그 앞에서 끊긴다. weeklyGoal은 세지 않는다. 오늘을 해제하면 그 localDate가 빠진다. 남은 체크인이 없으면 0이다. 남아 있으면 가장 최근 남은 날짜에서 다시 센다. 빈 날 없이 이어진 7일 뒤 오늘만 해제하면 가장 최근 날이 어제이므로 6이다. 날짜를 자르는 시각은 `HC-MIDNIGHT` (`_examples/DEV-70-오늘체크.HabitCheck.md`)이다.

| 단계 | 행위자 | 행동 |
|---|---|---|
| 1 | 사용자 | 목록에서 오늘을 체크한다 |
| 2 | 화면 | CheckInToday를 유스케이스에 넘긴다. DEV-35 |
| 3 | 유스케이스 | 오늘 행이 없으면 체크인을 하나 만든다. DEV-35 |
| 4 | 유스케이스 | DEV-22 AC-2. 3과 4는 순서가 아니라 갈림이다 |
| 5 | 유스케이스 | streak를 화면에 돌려준다 |
| 6 | 사용자 | 목록에서 오늘을 해제한다 |

아래 시퀀스는 오늘 체크의 갈림만 그린다. 해제는 위 표 6단계와 DEV-22 AC-3을 본다.

```mermaid
sequenceDiagram
  actor 사용자
  participant 화면
  participant 유스케이스
  participant 도메인
  participant 로컬DB
  사용자->>화면: 습관 체크
  화면->>유스케이스: CheckInToday
  유스케이스->>로컬DB: 오늘 있나
  alt 같은 날 없음
    유스케이스->>도메인: 규칙
    유스케이스->>로컬DB: 저장
  else 같은 날 있음
    유스케이스->>도메인: 기존 건으로 streak
  end
  유스케이스-->>화면: streak
```
