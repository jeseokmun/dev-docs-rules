## ＊ 목표
가입 없이 혼자 습관을 체크하고, streak를 신뢰할 수 있게 보여 주는 Android 앱 v1.

## ＊ 비범위
| 항목 | 이유 |
|---|---|
| 계정·클라우드 동기화 | v1 밖 |
| 소셜·친구·랭킹 | v1 밖 |
| iOS 동시 출시 | v1 제외 |
| Health 연동 | v1 밖 |
| 리마인더 푸시 | v1 밖 |

## ＊ 사용자·장면
| 구분 | 내용 |
|---|---|
| 사용자 | 혼자 운동·독서를 기록하려는 개인 |
| 장면 | 운동 직후 30초 안에 오늘 체크 + streak 확인 |

## ＊ 기능 요구
| # | 요구 | 검증 힌트 |
|---|---|---|
| 1 | 습관 이름·주당 목표 추가·수정·삭제 | 목록에 반영 |
| 2 | 오늘 날짜 기준 체크/해제 | 재실행해도 유지 |
| 3 | 습관별 streak 숫자 | 상세 화면 |
| 4 | 이번 주 체크 횟수 요약 | 목록/하단 |

## ○ 비기능
| 항목 | 목표 | 측정 |
|---|---|---|
| 오프라인 | 네트워크 없이 핵심 동작 | 비행기 모드 |
| 체크 반영 | 체감 1초 이내 | 추측 → DEV-68 |

## ○ 우선순위
| 요구 | Must/Should/Could |
|---|---|
| 체크·streak (1–3) | Must |
| 주간 요약 (4) | Should |
