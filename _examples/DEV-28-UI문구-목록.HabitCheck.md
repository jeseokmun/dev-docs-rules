## ＊ 톤
짧다. 광고 문장은 쓰지 않는다. 비하는 ＊ 금지. 한 키의 문구는 상태 표시이거나 명령형이다. 어느 쪽인지는 비고에 적는다.

## ＊ 문구
| 키 | KO문구 | 비고 |
|---|---|---|
| list.empty.title | 습관을 추가하세요 | 명령형 |
| list.pending | 오늘 안 함 | 아직 체크하지 않은 행. 상태 표시 |
| list.check | 오늘 함 | 오늘 체크된 행. 상태 표시. 명령형이 아님 |
| list.uncheck | 해제 | 오늘 체크를 끈다. 짧은 동사. 화면을 닫는 뜻의 취소와 겹치지 않게 해제로 쓴다 |

## ＊ 금지
| 금지 | 이유 |
|---|---|
| 실데이터·비밀 | SECURITY |
| 비하·조롱 | 실패를 나무라는 문장을 쓰지 않는다. DEV-10 |
| 번역되지 않은 영문 UI | 언어는 ko(DOC-CONFIG 샘플). 코드 키는 영문을 유지 |

## ○ i18n
| 항목 | 규칙 |
|---|---|
| 키 규칙 | 키 문자는 영문 소문자와 점이다. 두 조각은 `화면.요소`이고 `list.check`, `list.uncheck`, `list.pending`이 그 예다. 세 조각은 `화면.요소.역할`이고 `list.empty.title`이 그 예다. 화면에는 KO문구만 보인다 |
