# 템플릿 — DEV-42 이벤트메시지명세서 (v2.1)

> **v1 기준본 양식.** 개정할 때는 이 템플릿과 헌법 §0을 함께 고친다.
> **경로:** `{docs_root}/DEV-42-이벤트메시지명세서/DEV-42-{슬러그}.md` (다건)
> **용도:** 헌법 §5. 이벤트와 메시지 계약. HTTP API 계약은 DEV-40이다. 이 스키마에는 관련 문서 절이 없다.
> **가독성:** 표 우선. 산문은 요약 1–3문장 (헌법 §1.11). 한 파일은 한 이벤트 묶음이다 (헌법 §1.6).

## 표기

| 기호 | 의미 |
|---|---|
| ＊ | 필수. 헌법 §1.9 |
| ○ | 권장 절. 이 스키마의 권장 절은 ○ 재시도·멱등·순서뿐이다 |
| □ | 이 스키마의 표 헤더에는 □가 없다 |

## 문서 성숙도

| 단계 | 이 유형에서 |
|---|---|
| draft | ＊ 이벤트와 ＊ 페이로드 필드가 lint를 통과하면 된다 |
| 모르는 값 | 발행하지 않는 이벤트 이름을 지어 넣지 않는다. 칸은 `미결` 또는, 버스가 없으면 `없음` |
| 리뷰 | 보강 요청은 형과 필수 여부가 `미결`인 필드의 목록이다 |
| active | 핵심 미결이 닫히고, 발행자와 구독자를 코드와 다시 맞춰 볼 수 있을 때 |
| 어긋남 | 페이로드가 바뀌면 이 파일을 고치거나 deprecated로 둔다 |

## 사람 검토

항목 이름은 복사용 본문의 제목과 같다.

| 항목 | 사람이 볼 것 |
|---|---|
| ＊ 이벤트 | 이벤트, 페이로드 요약, 발행자, 구독자. 이벤트가 없으면 네 칸에 `없음`과 이유를 적는다. `이름 / 채널`처럼 두 후보를 슬래시로 이어 두면 칸이 `…`가 아니라 자리표시로 잡히지 않는다 |
| ＊ 페이로드 필드 | 필드, 형, 필수, 설명. 필수 칸에는 확인된 예 또는 아니오를 적는다. `Y/N`은 아직 고르지 않은 자리로 남기면 lint를 통과해 버리므로 쓰지 않는다 |
| ○ 재시도·멱등·순서 | 열은 항목·규칙이다. 복사용 세 행의 이름 재시도, 멱등, 순서는 스키마 키가 아니다. 해당 없는 행은 지운다. 규칙을 모르면 절 전체를 지우고 미결에 남긴다 |

제품 문서에 스키마에 없는 절을 더해도 `check_file`은 그 제목 자체를 실패로 보지 않는다. 링크가 필요하면 헤더 범위나 미결의 다음에 할 일에 경로를 적는다. 이 템플릿 파일에는 스키마에 없는 `○` 제목을 넣지 않는다. schema_sync가 그 제목을 optional과 맞춘다.

| 경로 | `{docs_root}/DEV-42-이벤트메시지명세서/DEV-42-{슬러그}.md` |

| 제목 | `#` 줄에 `DEV-42`가 단어로 있다 |
| 헤더 | 상태·코드·마지막 갱신·범위·비범위. 코드는 DEV-42. 날짜는 달력의 YYYY-MM-DD |
| 상태 | 기본 draft, active, deprecated. DOC-CONFIG `statuses`가 있으면 그 목록 |
| 자리표시 | 필수 칸의 `…`는 실패한다. 앞뒤에 다른 글자가 붙은 말줄임은 그 검사가 놓친다 |
| 빈 칸 | `비고`와 `□` 헤더가 없다. 빈 칸은 EMPTY_CELL |
| 선택 절 | ○ 재시도·멱등·순서의 열과 자리표시는 검사하지 않는다. 복사용 열은 항목·규칙. 그 표의 `…`는 FAKEFILL이 아니므로 규칙을 모르면 절을 지운다 |
| 미결 | 스키마 열은 ID·미결·다음에 할 일. 열 이름은 검사하지 않는다. 빈칸은 EMPTY_CELL |

| 필수 제목 | 스키마 | lint |
|---|---|---|
| ＊ 이벤트 | table. 이벤트, 페이로드, 발행자, 구독자. min_rows 1 | 열 순서, 1행 이상, 빈 칸, 자리표시 |
| ＊ 페이로드 필드 | table. 필드, 형, 필수, 설명. min_rows 1 | 열 순서, 1행 이상, 빈 칸, 자리표시 |

## 복사한 뒤

이벤트 네 칸과 페이로드 네 칸의 `…`는 바꾸기 전에 lint가 실패한다. 이벤트가 없으면 네 칸에 `없음`과 이유를 적고, 페이로드 필드도 `없음`으로 맞춘다. 필드가 둘 이상이면 행을 더한다. 재시도·멱등·순서에서 규칙이 `…`인 행은 선택 표라 lint가 놓친다. 확인 전이면 그 절을 지운다. 헤더의 `관련 문서` 행은 헌법 §4의 선택 항목이라 본문 H2가 아니다.
