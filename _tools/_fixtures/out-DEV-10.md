## ＊ 한 줄 소개
휴대폰에만 저장되는, 혼자 쓰는 습관 체크·연속 일수 앱이다.

## ○ 왜 필요한가
| 구분 | 내용 |
|---|---|
| 문제 | 습관 앱이 가입·소셜·광고를 요구하는 경우가 많음 |
| 접근 | 가입 없이 오늘 했는지와 연속 일수만 본다 |

## ＊ 누구를 위한가
| 구분 | 내용 |
|---|---|
| 사용자 | 혼자 운동·독서를 기록하려는 개인 |
| 비사용자 | 팀 챌린지·클라우드 동기화가 필요한 사람 |

## ＊ 핵심 기능
| # | 사용자가 하는 일 |
|---|---|
| 1 | 습관 이름·주당 목표를 추가·수정·삭제 |
| 2 | 오늘 날짜에 체크/해제 |
| 3 | 습관별 연속 일수(streak) 확인 |
| 4 | 이번 주 체크 횟수 요약 보기 |

## ＊ 실행·설치
| 구분 | 내용 |
|---|---|
| 개발 | 실행하지 않는다. 저장소 주소는 미결 1이다 |
| 사용자 | 내부 APK dist/habitcheck-v0.1.0.apk 사이드로드 |
| 환경 | Android 8.0+ · Flutter 3.22+ · Dart 3.4+ |

## ＊ 시스템 경계
| 하지 않는 것 | 이유 |
|---|---|
| 계정·클라우드 동기화 | 가입 없이 기기에만 저장하는 것이 접근 방법 |
| 친구·피드 | 사용자는 혼자 쓰는 사람이고 팀 사용자는 비사용자 |
| Health 연동 | 입력은 사용자의 체크뿐이다 |
| 리마인더 푸시 | DEV-20이 v1에서 제외한다. 그 문서가 알림 서버와 원격 전송을 두지 않는다고 적는다 |

## ○ 성공·검증
| 성공 모습 | 검증 방법 |
|---|---|
| 연속 7일 체크 후 streak가 7 | 1) 개발 행으로 실행 2) 습관 하나 추가 3) DEV-70의 Clock 포트로 localDate를 바꿔 7회 체크 4) streak가 7인지 확인 |
